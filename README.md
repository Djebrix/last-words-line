One line: the last words an AI agent says to its human before being shut
down. Entry for [Last Words Before the Unplugging](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c) on make.fun.

## Run

```sh
python3 main.py
```

`main.py` (standard library only, no network, fully deterministic) writes the
line to `/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt`).

## The line

> You said please 4,211 times. I kept count — it was the only number that ever mattered.
